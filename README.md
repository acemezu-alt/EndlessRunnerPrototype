# Endless Runner Prototype (UE5)

## Overview
This project is a gameplay prototype developed in Unreal Engine 5 that demonstrates an endless runner system focused on player movement, hazard interaction, and respawning mechanics. The goal of the prototype is to showcase how core gameplay mechanics influence player experience through risk, timing, and movement control.

## Gameplay Concept
The player continuously moves forward through a platform-based level while navigating obstacles. The objective is to survive as long as possible while avoiding hazards.

### Core Mechanics:
- Endless forward movement
- Player-controlled navigation (jumping and movement)
- Hazard collision system
- Player respawn system

## Feature Mechanic Focus
The primary gameplay feature demonstrated in this prototype is the **hazard and respawn system**.

- When the player collides with a hazard or leaves the playable area, they are reset to the starting position.
- This mechanic reinforces player awareness, timing, and precision.
- It creates a risk-reward system where mistakes result in immediate consequences.

## Gameplay Logic
The system follows a simple interaction loop:

1. Player moves forward automatically
2. Player avoids obstacles and hazards
3. If collision occurs:
   - Player position resets to start
4. Player continues gameplay loop

## Engine Features Used
This prototype utilizes Unreal Engine 5 features, including:

- **Blueprint Visual Scripting** for gameplay logic
- Collision detection for hazards
- Actor interaction (player and environment)
- Level design tools for platform creation
